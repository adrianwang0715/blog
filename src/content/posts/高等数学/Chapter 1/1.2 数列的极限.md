## 一、数列极限的定义

### 定义 1（$\varepsilon$-$N$ 语言）

设 $\{x_n\}$ 为一数列，如果存在常数 $a$，对于任意给定的正数 $\varepsilon$（不论它多么小），总存在正整数 $N$，使得当 $n > N$ 时，不等式

$$|x_n - a| < \varepsilon$$

都成立，那么就称常数 $a$ 是数列 $\{x_n\}$ 的**极限**，或者称数列 $\{x_n\}$ **收敛于** $a$，记为

$$\lim_{n \to \infty} x_n = a \quad \text{或} \quad x_n \to a \quad (n \to \infty).$$

如果不存在这样的常数 $a$，就称数列 $\{x_n\}$ **没有极限**，或者说数列 $\{x_n\}$ 是**发散的**，习惯上也说 $\lim\limits_{n\to\infty} x_n$ 不存在。

> **注（$\varepsilon$ 的任意性）**：$\varepsilon$ 是**任意小**的正数；找 $N$ 时把 $\varepsilon$ 视为常数。$\varepsilon$ 具有任意性：取 $\dfrac{\varepsilon}{2}$、$2\varepsilon$、$\varepsilon^2$、$\sqrt{\varepsilon}$ 都是等价的。例如要求 $|x_n - a| < \dfrac{\varepsilon}{2}$ 也可以——只要 $\varepsilon$ 任意小即可。
>
> **几何意义**：$\lim\limits_{n\to\infty} a_n = a$ 必须保证：邻域 $U(a, \varepsilon)$ **内**有数列的无限多项（$a_n\ (n>N) \in U(a,\varepsilon)$），$U(a, \varepsilon)$ **外**至多 $N$ 项（有限项）。

## 二、用定义证明极限（$\varepsilon$-$N$ 法）

### 例题 1

常数列 $\{C\}$（$a_n = C$）有极限，且 $\lim\limits_{n \to \infty} a_n = C$。

**证**：$\forall\, \varepsilon > 0$，取 $N = 1$。当 $n > N$ 时，$|a_n - C| = 0 < \varepsilon$。$\blacksquare$

### 例题 2

证明 $\lim\limits_{n \to \infty} \dfrac{1}{n} = 0$。

**证**：$\forall\, \varepsilon > 0$，取 $N = \left\lfloor \dfrac{1}{\varepsilon} \right\rfloor + 1$。当 $n > N$ 时，

$$\left| \frac{1}{n} - 0 \right| = \frac{1}{n} < \frac{1}{N} < \frac{1}{1/\varepsilon} = \varepsilon. \qquad \blacksquare$$

### 例题 3

证明 $\lim\limits_{n \to \infty} \dfrac{3n^5 + n}{n^5 + 1} = 3$。

**分析**：$\forall\, \varepsilon > 0$，找 $N$ 使 $n > N$ 时

$$\left| \frac{3n^5 + n}{n^5 + 1} - 3 \right| = \frac{|n - 3|}{n^5 + 1} < \varepsilon.$$

当 $n \ge 3$ 时 $|n-3| \le n$，故

$$\frac{|n-3|}{n^5+1} \le \frac{n}{n^5} = \frac{1}{n^4} < \varepsilon \iff n > \sqrt[4]{\frac{1}{\varepsilon}}.$$

**证**：$\forall\, \varepsilon > 0$，取 $N = \left\lfloor \sqrt[4]{\dfrac{1}{\varepsilon}} \right\rfloor + 1$。当 $n > N \ge 3$ 时，

$$\left| \frac{3n^5+n}{n^5+1} - 3 \right| \le \frac{1}{n^4} < \varepsilon. \qquad \blacksquare$$

> **方法小结**：用定义证明极限的核心是"**放大**"——把 $|x_n - a|$ 放大成只含 $n$ 的简单式子，令其小于 $\varepsilon$ 解出 $N$。放大时可以用"分母变小、分子变大"等手段，代价是 $N$ 变大，但 $N$ 大小无所谓，存在即可。

### 例题 4

证明 $\lim\limits_{n \to \infty} \sqrt[n]{n} = 1$。

**证法一**（均值不等式放大）：$n \ge 2$ 时，

$$\sqrt[n]{n} = \sqrt[n]{\sqrt{n} \cdot \sqrt{n} \cdot 1 \cdots 1} < \frac{2\sqrt{n} + n - 2}{n} < 1 + \frac{2}{\sqrt{n}}.$$

只需 $\dfrac{2}{\sqrt{n}} < \varepsilon$，即 $\sqrt{n} > \dfrac{2}{\varepsilon}$，$n > \dfrac{4}{\varepsilon^2}$ 即可。

**证法二**（二项式展开）：设 $\sqrt[n]{n} - 1 = \lambda_n\ (\lambda_n > 0)$，则 $n = (1 + \lambda_n)^n$。由二项式定理，

$$n = \binom{n}{0} + \binom{n}{1}\lambda_n + \binom{n}{2}\lambda_n^2 + \cdots > \binom{n}{2}\lambda_n^2 = \frac{n(n-1)}{2}\lambda_n^2,$$

$$\therefore\ \lambda_n < \sqrt{\frac{2}{n}}.$$

**证明**：取 $N = \left\lfloor \dfrac{4}{\varepsilon^2} \right\rfloor + 1$。当 $n > N$ 时，

$$|\sqrt[n]{n} - 1| = \lambda_n < \sqrt{\frac{2}{n}} < \sqrt{\frac{2}{N}} < \sqrt{\frac{2}{4/\varepsilon^2}} < \varepsilon. \qquad \blacksquare$$

### 例题 5

证明 $\lim\limits_{n \to \infty} a^{\frac{1}{n}} = 1$（$a > 1$）。

**证**：$a^{1/n} > 1$，故 $|a^{1/n} - 1| = a^{1/n} - 1$。$\forall\, \varepsilon > 0$，找 $N$：只需

$$a^{\frac{1}{n}} < \varepsilon + 1 \iff \frac{1}{n}\ln a < \ln(\varepsilon + 1) \iff n > \frac{\ln a}{\ln(\varepsilon + 1)}.$$

取 $N = \left\lfloor \dfrac{\ln a}{\ln(\varepsilon+1)} \right\rfloor + 1$，则 $n > N$ 时 $|a^{1/n} - 1| < \varepsilon$。$\blacksquare$

### 例题 6

证明：$0 < q < 1$ 时，$\lim\limits_{n \to \infty} q^n = 0$。

**证**：$\forall\, \varepsilon > 0$，找 $N$：$|q^n - 0| < \varepsilon \iff q^n < \varepsilon \iff n\ln q < \ln\varepsilon$。

由 $0 < q < 1$ 得 $\ln q < 0$，两边除以 $\ln q$ 时**不等号反向**：

$$n > \frac{\ln \varepsilon}{\ln q}.$$

取 $N = \max\left\{ \left\lfloor \dfrac{\ln \varepsilon}{\ln q} \right\rfloor + 1,\ 1 \right\}$，则 $n > N$ 时 $|q^n| < \varepsilon$。$\blacksquare$

### 例题 7

证明数列 $x_n = (-1)^{n+1}\ (n = 1, 2, \cdots)$ 是发散的。

**证**：如果这数列收敛，根据定理 1 它必有唯一的极限，设极限为 $a$，即 $\lim\limits_{n\to\infty} x_n = a$。按数列极限的定义，对于 $\varepsilon = \dfrac{1}{2}$，$\exists$ 正整数 $N$，当 $n > N$ 时，$|x_n - a| < \dfrac{1}{2}$ 成立；即当 $n > N$ 时，$x_n$ 都在开区间 $\left(a - \dfrac{1}{2}, a + \dfrac{1}{2}\right)$ 内。

但这是不可能的，因为 $n \to \infty$ 时，$x_n$ 无休止地一再重复取得 $1$ 和 $-1$ 这两个数，而这两个数不可能同时属于长度为 $1$ 的开区间 $\left(a - \dfrac{1}{2}, a + \dfrac{1}{2}\right)$ 内。因此这数列发散。$\blacksquare$

## 三、数列极限的性质

### 定理 1（极限的唯一性）

如果数列 $\{x_n\}$ 收敛，那么它的极限唯一。

**证法一（反证法）**：假设同时有 $x_n \to a$ 及 $x_n \to b$，且 $a < b$。取 $\varepsilon = \dfrac{b-a}{2}$。因为 $\lim\limits_{n\to\infty} x_n = a$，故 $\exists$ 正整数 $N_1$，当 $n > N_1$ 时，不等式

$$|x_n - a| < \frac{b-a}{2}$$

都成立。同理，因为 $\lim\limits_{n\to\infty} x_n = b$，故 $\exists$ 正整数 $N_2$，当 $n > N_2$ 时，不等式

$$|x_n - b| < \frac{b-a}{2}$$

都成立。取 $N = \max\{N_1, N_2\}$，则当 $n > N$ 时两式同时成立。但由第一式有 $x_n < \dfrac{a+b}{2}$，由第二式有 $x_n > \dfrac{a+b}{2}$，这是不可能的，矛盾。$\blacksquare$

**证法二**：$\forall\, \varepsilon > 0$，当 $n$ 充分大时 $|x_n - a| < \dfrac{\varepsilon}{2}$ 且 $|x_n - b| < \dfrac{\varepsilon}{2}$，故

$$|a - b| = |(x_n - a) - (x_n - b)| \le |x_n - a| + |x_n - b| < \varepsilon.$$

由 $\varepsilon$ 任意小，$a - b = 0$，即 $a = b$。$\blacksquare$

### 定理 2（收敛数列的有界性）

如果数列 $\{x_n\}$ 收敛，那么数列 $\{x_n\}$ 一定有界。

**证**：因为数列 $\{x_n\}$ 收敛，设 $\lim\limits_{n\to\infty} x_n = a$。根据数列极限的定义，对于 $\varepsilon = 1$，$\exists$ 正整数 $N$，当 $n > N$ 时，不等式

$$|x_n - a| < 1$$

都成立。于是当 $n > N$ 时，

$$|x_n| = |(x_n - a) + a| \le |x_n - a| + |a| < 1 + |a|.$$

取 $M = \max\left\{ |x_1|, |x_2|, \cdots, |x_N|,\ 1 + |a| \right\}$，那么数列 $\{x_n\}$ 中的一切 $x_n$ 都满足不等式 $|x_n| \le M$。（前 $1 \sim N$ 项是**有限项**，取 max 即可收编。）$\blacksquare$

> **注**：有界 $\not\Rightarrow$ 收敛。反例：$x_n = (-1)^{n+1}$ 有界但发散（例题 7）。

### 性质 3（保序性）

设 $\lim\limits_{n\to\infty} a_n = a$，$\lim\limits_{n\to\infty} b_n = b$。

1. 若 $a > b$，则 $\exists\, N$，当 $n > N$ 时，$a_n > b_n$；
2. 若 $\exists\, N$，当 $n > N$ 时，$a_n > b_n$，则 $a \ge b$。

**证 (1)**：$\forall\, \varepsilon > 0$，使 $|a_n - a| < \varepsilon$ 且 $|b_n - b| < \varepsilon$（取两式的 $N$ 的较大者）。$\because\ a > b$，取 $\varepsilon = \dfrac{a-b}{2}$，则

$$b - \varepsilon < b_n < b + \varepsilon = \frac{a+b}{2} = a - \varepsilon < a_n < a + \varepsilon,$$

故 $a_n > b_n$。$\blacksquare$

**(2)**（反证）：若 $a < b$，由 (1) 知 $\exists\, N$，当 $n > N$ 时 $a_n < b_n$，与 $a_n > b_n$ 矛盾。故 $a \ge b$。$\blacksquare$

> **注**：(2) 中条件是严格不等号，结论只能得到 $a \ge b$（等号可能成立），如 $a_n = \frac{1}{n} > 0 = b_n$，但 $a = b = 0$。

**推论（保号性）**：设 $\lim\limits_{n\to\infty} a_n = a$。

1. 若 $a > 0$（或 $a < 0$），则 $\exists\, N$，当 $n > N$ 时，$a_n > 0$（或 $a_n < 0$）；
2. 若 $\exists\, N$，当 $n > N$ 时恒有 $a_n \ge 0$（或 $a_n \le 0$），则 $a \ge 0$（或 $a \le 0$）。

## 四、子列

**子列**：从数列 $\{a_n\}$ 中**依次**抽取无限多项，得

$$a_{n_1},\ a_{n_2},\ \cdots,\ a_{n_k},\ \cdots, \quad \text{其中}\ 1 \le n_1 < n_2 < \cdots < n_k < n_{k+1} < \cdots$$

称为 $\{a_n\}$ 的一个**子列**，记作 $\{a_{n_k}\}_{k=1}^\infty$。

### 性质 4（子列定理）

$$\lim_{n \to \infty} a_n = a \iff \text{任取一个子列}\ \{a_{n_k}\}\ \text{均有}\ \lim_{k \to \infty} a_{n_k} = a.$$

**证**（$\Rightarrow$）：设数列 $\{x_{n_k}\}$ 是数列 $\{x_n\}$ 的任一子列。

由于 $\lim\limits_{n\to\infty} x_n = a$，故 $\forall\, \varepsilon > 0$，$\exists$ 正整数 $N$，当 $n > N$ 时，$|x_n - a| < \varepsilon$ 成立。

取 $K = N$，则当 $k > K$ 时，$n_k > n_K = n_N \ge N$。于是 $|x_{n_k} - a| < \varepsilon$。这就证明了 $\lim\limits_{k\to\infty} x_{n_k} = a$。$\blacksquare$

（$\Leftarrow$）：整个数列本身也是自己的一个子列，显然成立。

> **应用**：常用于判断数列**无**极限——只需找到两个子列极限不同。例如 $x_n = (-1)^n$：奇数项子列 $\to -1$，偶数项子列 $\to 1$，故 $\lim\limits_{n\to\infty} (-1)^n$ 不存在。
