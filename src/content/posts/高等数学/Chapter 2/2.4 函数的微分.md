> 本节主线：**微分 = 增量的线性主部**。它回答一个比"导数"更细的问题——当自变量变化 $\Delta x$ 时，函数值变化了多少？答案是"线性部分 $f'(x_0)\Delta x$ + 高阶小量"。核心结论只有一条：**可微 $\iff$ 可导**，但由此得到的"微分形式不变性"与"以微分代换导数"的运算习惯，是后面积分与近似计算的基础。

## 一、可微函数的定义

### 定义 1（可微与微分）

**通俗地说**：如果函数的增量可以拆成"一个与 $\Delta x$ 成正比的线性部分"加上"比 $\Delta x$ 高阶的零头"，就称它可微——线性部分就是微分，也就是用切线代替曲线的那一段。

> **定义**：设 $y = f(x)$ 在点 $x_0$ 附近有定义。令
>
> $$\Delta x = x - x_0,$$
>
> 称其为**自变量在点 $x_0$ 处的增量**；相应的**函数增量**
>
> $$\Delta y = f(x) - f(x_0) = f(x_0 + \Delta x) - f(x_0)$$
>
> （也可记为 $\Delta f$）。如果存在**与 $\Delta x$ 无关的常数 $A$**，使得
>
> $$\Delta y = A\,\Delta x + o(\Delta x),$$
>
> 则称 $y = f(x)$ 在 $x_0$ 处**可微**，并称 $A\,\Delta x$ 为 $f$ 在 $x_0$ 处的**微分**，记为
>
> $$\left.\mathrm{d}f\right|_{x=x_0} \quad \text{或} \quad \left.\mathrm{d}y\right|_{x=x_0},$$
>
> 即
>
> $$\left.\mathrm{d}y\right|_{x=x_0} = \left.\mathrm{d}f\right|_{x=x_0} = A\,\Delta x.$$

### 定理 1（可微 $\iff$ 可导，且 $A = f'(x_0)$ 唯一）

**通俗地说**：可微与可导是同一件事，而且那个线性系数 $A$ 只能是导数——所以"微分"其实完全由导数决定。

> **定理**：$f$ 在 $x_0$ 处可微 $\iff$ $f$ 在 $x_0$ 处可导，此时
>
> $$A = f'(x_0) \quad \text{（值唯一！）}$$

**证（$\Rightarrow$）**：由于 $\Delta f = f(x_0 + \Delta x) - f(x_0) = A\,\Delta x + o(\Delta x)$，则

$$
f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
= \lim_{\Delta x \to 0} \frac{A\,\Delta x + o(\Delta x)}{\Delta x}
= A.
$$

故 $f$ 在 $x_0$ 处可导，且 $A = f'(x_0)$（**唯一性**：极限唯一，故 $A$ 唯一）。

**证（$\Leftarrow$）**：由于

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

存在，故

$$\frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x} = f'(x_0) + \alpha(\Delta x),$$

其中 $\alpha(\Delta x)$ 为 $\Delta x \to 0$ 时的**无穷小量**。两边乘 $\Delta x$：

$$\Delta f = f(x_0 + \Delta x) - f(x_0) = f'(x_0)\,\Delta x + \Delta x\cdot\alpha(\Delta x).$$

而

$$\frac{\left|\Delta x \cdot \alpha(\Delta x)\right|}{|\Delta x|} = \left|\alpha(\Delta x)\right| \to 0, \quad \text{即}\quad \Delta x\cdot\alpha(\Delta x) = o(\Delta x).$$

故 $\Delta f = f'(x_0)\Delta x + o(\Delta x)$，$f$ 在 $x_0$ 处可微，且 $A = f'(x_0)$。$\blacksquare$

**由此得到微分的计算公式**：

$$\boxed{\left.\mathrm{d}f\right|_{x=x_0} = f'(x_0)\,\Delta x}$$

**约定**：对自变量 $x$ 本身，取

$$\boxed{\Delta x \triangleq \mathrm{d}x} \qquad (\text{即自变量的微分就是它的增量})$$

于是

$$\boxed{\left.\mathrm{d}f\right|_{x=x_0} = f'(x_0)\,\mathrm{d}x}, \qquad \text{一般地}\quad \boxed{\mathrm{d}f = f'(x)\,\mathrm{d}x}$$

> **推论（导数就是"微商"）**：
>
> $$\boxed{\frac{\mathrm{d}f}{\mathrm{d}x} = f'(x)}$$
>
> 这正是 $\dfrac{\mathrm{d}y}{\mathrm{d}x}$ 这个记号的含义——**微分之商**。所以导数与微分只差"乘不乘 $\mathrm{d}x$"：导数是一个"比率"，微分是一个"量"。

### 定义 2（区间上可微与微分函数）

**通俗地说**：如果区间内每一点都可微，那么"微分"也随点变化，构成一个函数（微分函数）。

> **定义**：设 $y = f(x)$ 在区间 $I$ 中**每一点**均可微，即
>
> $$\Delta y = f(x + \Delta x) - f(x) = A(x)\,\Delta x + o(\Delta x)$$
>
> 成立，则称 $f$ 在区间 $I$ 上**可微**，称 $A(x)\Delta x$ 即 $f'(x)\mathrm{d}x$ 为 $f$ 在区间 $I$ 上的**微分函数**，记为 $\mathrm{d}f$ 或 $\mathrm{d}y$。即
>
> $$\mathrm{d}f(x) = A(x)\,\mathrm{d}x = f'(x)\,\mathrm{d}x, \qquad x \in I,\quad \mathrm{d}x = \Delta x \in (-\infty, +\infty).$$
>
> 于是
>
> $$\frac{\mathrm{d}f}{\mathrm{d}x} = f'(x).$$

> **几何意义**：$\Delta y$ 是曲线 $y = f(x)$ 上纵坐标的**真实增量**，$\mathrm{d}y = f'(x_0)\Delta x$ 是**切线**上纵坐标的增量，二者相差 $o(\Delta x)$。所以"可微"的几何含义就是：**曲线在这一点附近可以被切线很好地近似**，由此得到近似公式
>
> $$f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\,\Delta x.$$

## 二、微分的运算法则（2°）

### 定理 2（四则运算）

**通俗地说**：微分法则与导数法则一一对应，只是每个导数后面都乘上 $\mathrm{d}x$——因为 $\mathrm{d}(fg) = (fg)'\mathrm{d}x$。

> **定理**：设 $f, g$ 均可微，$\alpha, \beta$ 为常数，则
>
> $$\text{(1)}\ \mathrm{d}(\alpha f + \beta g) = \alpha\,\mathrm{d}f + \beta\,\mathrm{d}g;$$
>
> $$\text{(2)}\ \mathrm{d}(f \cdot g) = g\,\mathrm{d}f + f\,\mathrm{d}g;$$
>
> $$\text{(3)}\ \text{当}\ g \ne 0\ \text{时},\quad \mathrm{d}\!\left(\frac{f}{g}\right) = \frac{g\,\mathrm{d}f - f\,\mathrm{d}g}{g^2}.$$

**证（3）**：

$$
\mathrm{d}\!\left(\frac{f}{g}\right) = \left(\frac{f}{g}\right)'_x \mathrm{d}x
= \frac{f'g - fg'}{g^2}\,\mathrm{d}x
= \frac{g\,f'\mathrm{d}x - f\,g'\mathrm{d}x}{g^2}
= \frac{g\,\mathrm{d}f - f\,\mathrm{d}g}{g^2}.
$$

（(1)(2) 同理：用相应导数公式乘 $\mathrm{d}x$ 即可。）$\blacksquare$

### 一阶微分形式不变性

**通俗地说**：不管 $u$ 是自变量还是"中间变量"，$\mathrm{d}f = f'(u)\mathrm{d}u$ 这个形式都不变——这正是微分记号比导数记号更好用的地方（换元时不用管谁是自变量）。

**证**：设 $y = f(u)$ 可微。

- 当 $u$ 为**自变量**时：
  $$\mathrm{d}f(u) = f'(u)\,\mathrm{d}u;$$
- 当 $u = g(x)$ 为**中间变量**（因变量）时：
  $$
  \mathrm{d}f(u) = \mathrm{d}f(g(x)) = \left[f(g(x))\right]'_x \mathrm{d}x
  = f'\!\left(g(x)\right)g'(x)\,\mathrm{d}x
  = f'\!\left(g(x)\right)\mathrm{d}g(x) = f'(u)\,\mathrm{d}u.
  $$

两种情形结果完全一样，故

$$\boxed{\mathrm{d}f(u) = f'(u)\,\mathrm{d}u\ \text{恒成立}}$$

即**一阶微分形式不变性**：无论 $u$ 是自变量还是因变量，一阶微分的形式都是"导数 × 微分"。$\blacksquare$

> **注**：
> 1. $\mathrm{d}(\mathrm{d}x) = 0$（当 $x$ 为自变量时，$\mathrm{d}x = \Delta x$ 是常数）；
> 2. 高阶微分**没有**形式不变性（$\mathrm{d}^2 f \ne f''(u)\mathrm{d}u^2$，除非 $u$ 是自变量）——这是微分与导数最大的区别，也是后面 Taylor 公式、积分换元时容易踩的坑。

## 三、基本微分公式

由 $\mathrm{d}f = f'(x)\mathrm{d}x$，把 2.1–2.2 的导数公式逐个乘上 $\mathrm{d}x$：

| 编号 | 公式 |
|---|---|
| (1) | $\mathrm{d}(C) = 0$ |
| (2) | $\mathrm{d}(x^\mu) = \mu x^{\mu-1}\,\mathrm{d}x$ |
| (3) | $\mathrm{d}(a^x) = a^x \ln a\,\mathrm{d}x$ |
| (4) | $\mathrm{d}(e^x) = e^x\,\mathrm{d}x$ |
| (5) | $\mathrm{d}(\log_a x) = \dfrac{\mathrm{d}x}{x\ln a}$ |
| (6) | $\mathrm{d}(\ln\lvert x\rvert) = \dfrac{\mathrm{d}x}{x}$ |
| (7) | $\mathrm{d}(\sin x) = \cos x\,\mathrm{d}x$ |
| (8) | $\mathrm{d}(\cos x) = -\sin x\,\mathrm{d}x$ |
| (9) | $\mathrm{d}(\tan x) = \sec^2 x\,\mathrm{d}x$ |
| (10) | $\mathrm{d}(\cot x) = -\csc^2 x\,\mathrm{d}x$ |
| (11) | $\mathrm{d}(\sec x) = \sec x\tan x\,\mathrm{d}x$ |
| (12) | $\mathrm{d}(\csc x) = -\csc x\cot x\,\mathrm{d}x$ |
| (13) | $\mathrm{d}(\arcsin x) = \dfrac{\mathrm{d}x}{\sqrt{1 - x^2}}$ |
| (14) | $\mathrm{d}(\arccos x) = -\dfrac{\mathrm{d}x}{\sqrt{1 - x^2}}$ |
| (15) | $\mathrm{d}(\arctan x) = \dfrac{\mathrm{d}x}{1 + x^2}$ |
| (16) | $\mathrm{d}(\text{arccot}\,x) = -\dfrac{\mathrm{d}x}{1 + x^2}$ |

> (17) 的验证：$\left(\ln\left\lvert x+\sqrt{x^2\pm a^2}\right\rvert\right)' = \dfrac{1}{x+\sqrt{x^2\pm a^2}}\left(1 + \dfrac{x}{\sqrt{x^2\pm a^2}}\right) = \dfrac{1}{\sqrt{x^2\pm a^2}}$（当 $x^2 \pm a^2 > 0$ 且 $x + \sqrt{x^2\pm a^2} \ne 0$）。

## 四、例题

### 例题 1

设 $\{\alpha_n\}$ 和 $\{\beta_n\}$ 为**正数**数列，且

$$\lim_{n \to \infty} \alpha_n = 0, \qquad \lim_{n \to \infty} \beta_n = 0,$$

$f$ 在 $x_0$ 处可导。求

$$\lim_{n \to \infty} \frac{f(x_0 + \alpha_n) - f(x_0 - \beta_n)}{\alpha_n + \beta_n}.$$

**解**：由 $f$ 在 $x_0$ 可导 $\iff$ 可微，有增量公式

$$f(x_0 + \Delta x) - f(x_0) = f'(x_0)\,\Delta x + o(\Delta x).$$

分别代入 $\Delta x = \alpha_n$、$\Delta x = -\beta_n$：

$$f(x_0 + \alpha_n) = f(x_0) + f'(x_0)\alpha_n + o(\alpha_n),$$

$$f(x_0 - \beta_n) = f(x_0) - f'(x_0)\beta_n + o(\beta_n).$$

两式相减：

$$f(x_0 + \alpha_n) - f(x_0 - \beta_n) = f'(x_0)(\alpha_n + \beta_n) + o(\alpha_n) + o(\beta_n).$$

两边除以 $\alpha_n + \beta_n$：

$$
\frac{f(x_0+\alpha_n) - f(x_0-\beta_n)}{\alpha_n + \beta_n}
= f'(x_0) + \underbrace{\frac{o(\alpha_n)}{\alpha_n}\cdot\frac{\alpha_n}{\alpha_n+\beta_n}}_{\to 0}
+ \underbrace{\frac{o(\beta_n)}{\beta_n}\cdot\frac{\beta_n}{\alpha_n+\beta_n}}_{\to 0},
$$

其中 $\dfrac{o(\alpha_n)}{\alpha_n} \to 0$、$\dfrac{o(\beta_n)}{\beta_n} \to 0$ 而 $0 < \dfrac{\alpha_n}{\alpha_n+\beta_n} < 1$、$0 < \dfrac{\beta_n}{\alpha_n+\beta_n} < 1$ 均为**有界量**（无穷小 × 有界 = 无穷小）。故

$$\boxed{\lim_{n \to \infty} \frac{f(x_0+\alpha_n) - f(x_0-\beta_n)}{\alpha_n+\beta_n} = f'(x_0)} \qquad \blacksquare$$

> **方法小结**：这类"分子是两处函数值之差、分母是两段增量之和"的题，用**增量公式** $\Delta f = f'\,\Delta x + o(\Delta x)$ 比直接用导数定义灵活得多——因为导数定义式的分子分母必须配同一个 $\Delta x$，而 $o(\Delta x)$ 可以单独拿出来做放缩。
>
> **常见特例**：取 $\alpha_n = \beta_n = \dfrac{1}{n}$，得 $\dfrac{n}{2}\left[f\left(x_0 + \frac1n\right) - f\left(x_0 - \frac1n\right)\right] \to f'(x_0)$，即对称差商 $\dfrac{f(x_0+h)-f(x_0-h)}{2h} \to f'(x_0)$。注意这只是**单向**结论：$f$ 可导能推出对称差商收敛，但对称差商收敛**不能**推出可导——如 $f(x)=|x|$ 在 $0$ 处的对称差商恒为 $0$，而 $f'(0)$ 并不存在。

## 五、高阶微分

**通俗地说**：微分再微分，就是二阶微分。$x$ 作自变量时它恰好等于 $f''(x)\mathrm{d}x^2$——这也正是 $\dfrac{\mathrm{d}^2 f}{\mathrm{d}x^2}$ 这个记号的含义。

### 1. 二阶微分的定义与计算公式

**定义**：$\mathrm{d}^2 f \triangleq \mathrm{d}\left(\mathrm{d}f\right)$。

当 $x$ 为**自变量**时，$\mathrm{d}x = \Delta x$ 与 $x$ 无关（是常数），故

$$\mathrm{d}(\mathrm{d}x) = 0, \qquad \mathrm{d}^2 x = 0.$$

于是

$$
\begin{aligned}
\mathrm{d}^2 f(x) &= \mathrm{d}\left(f'(x)\,\mathrm{d}x\right)
= \mathrm{d}\!\left(f'(x)\right)\cdot \mathrm{d}x + f'(x)\cdot \mathrm{d}(\mathrm{d}x) \\
&= f''(x)\,\mathrm{d}x\cdot \mathrm{d}x + f'(x)\cdot 0
= f''(x)\,(\mathrm{d}x)^2.
\end{aligned}
$$

记 $(\mathrm{d}x)^2 = \mathrm{d}x^2$，即得

$$\boxed{\mathrm{d}^2 f = f''(x)\,\mathrm{d}x^2}, \qquad \text{从而}\quad \boxed{\frac{\mathrm{d}^2 f}{\mathrm{d}x^2} = f''(x)}$$

同理，$n$ 阶微分为

$$\mathrm{d}^n f = f^{(n)}(x)\,\mathrm{d}x^n.$$

### 2. 二阶微分**没有**形式不变性（一阶才有）

若 $u = g(x)$ 是**中间变量**，则 $\mathrm{d}u$ 不再是与 $x$ 无关的常数，$\mathrm{d}^2 u \ne 0$。此时

$$
\mathrm{d}^2 f = \mathrm{d}\left(f'(u)\,\mathrm{d}u\right)
= f''(u)\,\mathrm{d}u^2 + f'(u)\,\mathrm{d}^2 u,
$$

多出来的 $f'(u)\,\mathrm{d}^2u$ 一般不为零，故

$$\mathrm{d}^2 f \ne f''(u)\,\mathrm{d}u^2 \quad (\text{当 } u \text{ 为中间变量时}).$$

> **结论**：**一阶微分形式不变，二阶及以上不再具有形式不变性**。所以写 $\dfrac{\mathrm{d}^2 y}{\mathrm{d}x^2}$ 时，只有 $x$ 是自变量才能直接读成"$y$ 对 $x$ 求两次导"。

## 六、微分的应用：近似计算

**原理**：由 $\Delta y = f'(x_0)\Delta x + o(\Delta x)$，当 $|\Delta x|$ 很小时

$$\boxed{f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\,\Delta x}$$

即"**用切线代替曲线**"，误差是 $o(\Delta x)$（比 $\Delta x$ 更高阶）。

### 例题 2

求 $\sqrt[3]{26}$ 的近似值。

**解**：把 $26$ 写成"离它最近的立方数 + 小增量"：

$$\sqrt[3]{26} = \sqrt[3]{27}\cdot\sqrt[3]{\frac{26}{27}} = 3\sqrt[3]{1 - \frac{1}{27}}.$$

令

$$f(x) = 3\sqrt[3]{x}, \qquad x_0 = 1, \quad \Delta x = -\frac{1}{27},$$

则 $f(1) = 3$，

$$f'(x) = 3\cdot\frac{1}{3}x^{-\frac{2}{3}} = x^{-\frac{2}{3}}, \qquad f'(1) = 1.$$

由微分近似：

$$
\sqrt[3]{26} = f\!\left(1 - \frac{1}{27}\right) \approx f(1) + f'(1)\Delta x
= 3 + 1\cdot\left(-\frac{1}{27}\right) = 3 - \frac{1}{27} = \frac{80}{27} \approx \boxed{2.96296}
$$

（真值 $\sqrt[3]{26} \approx 2.962496$，误差约 $4.6\times10^{-4}$，相对误差约 $1.6\times10^{-4}$。）

> **要点**：取 $x_0$ 的原则是"**$f(x_0)$ 与 $f'(x_0)$ 都能口算，且 $\Delta x$ 尽量小**"。所以 $\sqrt[3]{26}$ 要拆成 $27$ 而不是 $25$。

## 七、典型例题

### 例题 3（用形式不变性求微分）

设 $f(x) = e^{x\sin(\ln x)}\ (x > 0)$，求 $\mathrm{d}f$ 与 $f'(x)$。

**解**：由一阶微分形式不变性，从外往里逐层"$d$ 出去"：

$$
\begin{aligned}
\mathrm{d}f &= \mathrm{d}\left(e^{x\sin\ln x}\right)
= e^{x\sin\ln x}\,\mathrm{d}\left(x\sin\ln x\right) \\
&= e^{x\sin\ln x}\left[\sin\ln x\,\mathrm{d}x + x\,\mathrm{d}\left(\sin\ln x\right)\right] \\
&= e^{x\sin\ln x}\left[\sin\ln x\,\mathrm{d}x + x\cos\ln x\cdot\frac{1}{x}\mathrm{d}x\right] \\
&= e^{x\sin\ln x}\left(\sin\ln x + \cos\ln x\right)\mathrm{d}x.
\end{aligned}
$$

于是

$$\boxed{\mathrm{d}f = e^{x\sin\ln x}\left(\sin\ln x + \cos\ln x\right)\mathrm{d}x}, \qquad \boxed{f'(x) = e^{x\sin\ln x}\left(\sin\ln x + \cos\ln x\right)}$$

> **要点**：求 $\mathrm{d}f$ 时不必先算出 $f'(x)$ 再乘 $\mathrm{d}x$——直接对 $f$ 用微分法则，最后把 $\mathrm{d}x$ 提出来，$\mathrm{d}f$ 除以 $\mathrm{d}x$ 就是 $f'$。这就是"**导数 = 微商**"的实用价值。

### 例题 4（可导的充要条件辨析）

设 $f(x)$ 在 $(x_0 - \delta, x_0 + \delta)$ 上有定义，则 $f'(x_0)$ 存在的**充要条件**是（　　）

$$
\begin{aligned}
\text{(A)}\ & \lim_{n \to \infty} n\left[f\left(x_0 + \tfrac{1}{n}\right) - f(x_0)\right]\ \text{存在}; \\
\text{(B)}\ & \lim_{h \to 0} \frac{f\big(x_0 + (1 - \cos h)\big) - f(x_0)}{1 - \cos h}\ \text{存在}; \\
\text{(C)}\ & \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0 - h)}{2h}\ \text{存在}; \\
\text{(D)}\ & \lim_{h \to 0} \frac{f\left(x_0 + e^{\sin h} - 1\right) - f(x_0)}{\ln(1 - 2h)}\ \text{存在}.
\end{aligned}
$$

**答案：(D)**。

**分析**：判断这类题的唯一标准——**增量 $\Delta x$ 是否"双向、连续地"趋于 $0$，且分母与 $\Delta x$ 同阶、符号对应**。逐项验证（反例统一取 $f(x) = |x|$，$x_0 = 0$，此时 $f'(0)$ 不存在）：

**(A)** 只取 $\Delta x = \dfrac1n \to 0^+$，是**离散（甚至不保证f(x)有极限）的单向**逼近：

$$\lim_{n\to\infty} n\left[f\left(\tfrac1n\right) - f(0)\right] = \lim_{n\to\infty} n\cdot\frac1n = 1$$

存在，但 $f'(0)$ 不存在 $\implies$ (A) 不行。

**(B)** 增量 $\alpha = 1 - \cos h \ge 0$，$h \to 0$ 时 $\alpha \to 0^{\,+}$，**只从右侧**逼近，最多只能推出右导数：

$$\lim_{h\to0}\frac{\left|\,0 + \alpha\,\right| - 0}{\alpha} = \lim_{h\to0}\frac{\alpha}{\alpha} = 1$$

存在，但 $f'(0)$ 不存在 $\implies$ (B) 不行。（把 $f(x)=|x|$ 换成 $f(x) = \begin{cases} 2x, & x < 0 \\ x, & x \ge 0\end{cases}$ 也能看出：该极限 $=1=f'_+(0)$，而 $f'_-(0) = 2$，仍不可导。）

**(C)** 对称差商，增量**左右同时**但**分子是两处函数值之差**，不保证与单侧对应：
由导数的定义，必须是一动减一定

$$\lim_{h\to0}\frac{|h| - |-h|}{2h} = 0$$

存在，但 $f'(0)$ 不存在 $\implies$ (C) 不行。

**(D)** 令 $\alpha = e^{\sin h} - 1$，则 $\alpha \to 0$ 且 $h \mapsto \alpha$ **严格单调、双向一一对应**（$h>0 \Leftrightarrow \alpha>0$）。又

$$\ln(1-2h) \sim -2h, \qquad \alpha = e^{\sin h} - 1 \sim \sin h \sim h \implies \ln(1-2h) \sim -2\alpha.$$

故

$$
\lim_{h\to0}\frac{f(x_0+\alpha) - f(x_0)}{\ln(1-2h)}
= \lim_{\alpha\to0}\frac{f(x_0+\alpha) - f(x_0)}{-2\alpha}
= -\frac{1}{2}\lim_{\alpha\to0}\frac{f(x_0+\alpha) - f(x_0)}{\alpha}
= -\frac{1}{2}f'(x_0).
$$

于是 (D) 的极限存在 $\iff$ $f'(x_0)$ 存在（两者相差常数因子 $-\tfrac12$）。$\blacksquare$

> **方法小结**：代换 $\Delta x = \alpha(h)$ 后要检查三件事——① $\alpha(h)$ 在 $h \to 0$ 时**双向**趋于 $0$（不是只从一侧，也不是离散取值）；② $h \mapsto \alpha$ **一一对应**（严格单调）；③ 分母与 $\alpha$ **同阶**。三者齐备时，该极限 $= c\,f'(x_0)$（$c \ne 0$），与可导互为充要。

### 例题 5（分段函数 + 夹逼）

设

$$f(x) = \begin{cases} \sin x, & x \le 0, \\ \text{满足}\ \ln(1+x) < f(x) < x, & 0 < x. \end{cases}$$

问 $f$ 在 $x = 0$ 处是否连续、是否可导？若可导，求 $\left.\mathrm{d}f\right|_{x=0}$。

**解**：

**（1）连续性**：$f(0) = \sin 0 = 0$，左极限 $\lim\limits_{x \to 0^-} f(x) = 0 = f(0)$ ✓。

右侧：$x \to 0^+$ 时 $\ln(1+x) \to 0$、$x \to 0$，由 $\ln(1+x) < f(x) < x$ 及夹逼定理，

$$\lim_{x \to 0^+} f(x) = 0 = f(0).$$

故 $f$ 在 $x = 0$ 处**连续**。

**（2）可导性**：

左导数（$x \le 0$ 段是 $\sin x$）：

$$f'_-(0) = \left.(\sin x)'\right|_{x=0} = \cos 0 = 1.$$

右导数：由 $0 < x$ 时 $\ln(1+x) < f(x) < x$，两边同除以 $x > 0$（不等号不变）：

$$\frac{\ln(1+x)}{x} < \frac{f(x)}{x} < 1,$$

而 $\lim\limits_{x\to0^+}\dfrac{\ln(1+x)}{x} = 1$（1.6 推论 2），故由夹逼

$$f'_+(0) = \lim_{x \to 0^+}\frac{f(x) - f(0)}{x} = \lim_{x\to0^+}\frac{f(x)}{x} = 1 = f'_-(0).$$

故 $f'(0) = 1$，$f$ 在 $x = 0$ 处可导，且

$$\boxed{\left.\mathrm{d}f\right|_{x=0} = f'(0)\,\mathrm{d}x = \mathrm{d}x}$$

> **要点**：题目只给了 $f$ 的**不等式约束**（没给解析式），这种题一律走"**夹逼**"：连续靠 $\ln(1+x) \to 0$、$x \to 0$ 夹出来，导数靠 $\dfrac{\ln(1+x)}{x} \to 1$ 与 $1$ 夹出来。

### 例题 6（阶梯函数也可微）

设

$$
f(x) = \begin{cases}
x, & x \le 0, \\[4pt]
\dfrac{1}{n}, & x > 0\ \text{且}\ \dfrac{1}{n+1} < x \le \dfrac{1}{n},\ n \in \mathbb{Z}_+ .
\end{cases}
$$

证明：$f$ 在 $x = 0$ 处可微，且 $\left.\mathrm{d}f\right|_{x=0} = \mathrm{d}x$。

**证**：$f(0) = 0$。

**右导数**：当 $\dfrac{1}{n+1} < x \le \dfrac{1}{n}$ 时，$f(x) = \dfrac1n$，于是

$$f'_+(0) = \lim_{x\to0^+}\frac{f(x) - f(0)}{x} = \lim_{x\to0^+}\frac{1}{nx}.$$

由 $\dfrac{1}{n+1} < x \le \dfrac{1}{n}$ 得 $\dfrac{n}{n+1} < nx \le 1$，取倒数：

$$1 \le \frac{1}{nx} < \frac{n+1}{n} = 1 + \frac1n,$$

而 $x \to 0^+$ 时（因 $x \le \frac1n$）$n \to \infty$，故 $1 + \dfrac1n \to 1$，由夹逼

$$f'_+(0) = 1.$$

**左导数**：$x \le 0$ 段为 $f(x) = x$，

$$f'_-(0) = \left.x'\right|_{x=0} = 1 = f'_+(0).$$

故 $f'(0) = 1$，$f$ 在 $0$ 处可微，且

$$\boxed{\left.\mathrm{d}f\right|_{x=0} = \mathrm{d}x}$$

> **要点**：这个例子说明"**函数图像可以有无穷多个跳跃台阶，仍然可微**"——台阶高度是 $\frac1n - \frac{1}{n+1} = \frac{1}{n(n+1)}$，量级 $O\!\left(\frac{1}{n^2}\right)$，而台阶宽度是 $O\!\left(\frac1n\right)$，比值 $\to 0$，所以 $\frac{f(x)}{x} \to 1$。可微性只关心"差商是否有极限"，不关心曲线好不好看。
