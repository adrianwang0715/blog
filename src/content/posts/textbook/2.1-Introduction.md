# 第 2 章：用对象构建抽象

## 2.1   引言

第 1 章中，我们关注的是计算过程以及函数在程序设计中的作用。我们看到了如何使用原始数据（数字）和原始操作（算术运算），如何通过复合与控制构造复合函数，以及如何通过为过程命名来创建函数抽象。我们还看到，高阶函数（higher-order function）让我们能够以通用的计算方法来操作、并由此推理，从而增强了语言的威力。这正是编程的精髓所在。

本章聚焦于数据。数据使我们能够利用目前所掌握的计算工具来表示和操作关于世界的信息。没有数据结构的程序或许足以探索数学性质。但现实世界中的现象具有复杂的结构，最好用*复合数据*（compound data）来表示。有了结构化数据，程序就能模拟并推理人类知识与经验的任意领域。随着互联网的爆炸式增长，海量关于世界的结构化信息如今在网上对所有人免费开放。

### 2.1.1   对象隐喻

在本书开头，我们区分了函数与数据：函数执行操作，而数据被操作。当我们将函数值也纳入数据之列时，我们就承认了数据同样可以拥有行为。函数可以作为数据被操作，也可以被调用来执行计算。

在本书中，*对象*（object）将作为我们的核心编程隐喻，用来表示那些同样具有行为的数值。对象表示信息，同时也像它们所表示的抽象概念一样*行动*。一个对象如何与其他对象交互的逻辑，与编码该对象值的信息捆绑在一起。当一个对象被打印时，它知道自己如何以字母和数字的形式把自己拼写出来。如果一个对象由若干部分复合而成，它知道如何按需揭示这些部分。对象既是信息又是过程，二者捆绑在一起，用以表示复杂事物的性质、交互和行为。

对象隐喻在 Python 中通过专门的对象语法以及相关术语来实现，我们可以通过例子来介绍它们。日期（date）是一种简单的对象。

```python
>>> from datetime import date
```

名字 `date` 绑定到一个*类*（class）。类表示某一种对象。一个个具体的日期称为该类的*实例*（instance），它们可以通过在描述该实例的参数上调用该类来*构造*。

```python
>>> today = date(2013, 9, 25)
```

尽管 `today` 是由原始数字构造出来的，它的行为却像一个日期。例如，将它从另一个日期中减去会得到一个时间差，我们可以通过调用 `str` 把它显示为一行文本。

```python
>>> str(date(2013, 10, 1) - today)
'6 days, 0:00:00'
```

对象拥有*属性*（attribute），即作为对象一部分的具名值。在 Python 中，与许多其他编程语言一样，我们使用点记法（dot notation）来指定对象的某个属性。

> <expression> . <name>

上式中，`<expression>` 求值为一个对象，`<name>` 是该对象某个属性的名字。

与我们此前考虑过的名字不同，这些属性名在全局环境中并不可用。相反，属性名是点号之前那个具体对象实例所特有的。

```python
>>> today.year
2013
```

对象还拥有*方法*（method），即取值为函数的属性。用隐喻的说法，我们说对象「知道」如何执行这些方法。从实现上看，方法是从其参数和其对象二者计算出结果的函数。例如，`today` 的 `strftime` 方法（一个经典函数名，意在唤起「时间的字符串格式」，string format of time）接受单个参数，用以指定如何显示日期（例如 `%A` 表示星期几应当拼写完整）。

```python
>>> today.strftime('%A, %B %d')
'Wednesday, September 25'
```

计算 `strftime` 的返回值需要两个输入：描述输出格式的字符串，以及捆绑在 `today` 中的日期信息。该方法内部应用了日期特有的逻辑来得到这一结果。我们从未说明 2013 年 9 月 25 日是星期三，但知道自己是一周中的哪一天，正是身为一个日期所应有含义的一部分。通过将行为与信息捆绑在一起，这个 Python 对象为我们提供了一个令人信服、自成一体的日期抽象。

点记法在 Python 中提供了另一种形式的组合表达式。点记法也有明确定义的求值过程。不过，要精确阐述点记法是如何求值的，得等到我们在接下来若干节中引入面向对象编程的完整范式之后。

### 2.1.2   原生数据类型

Python 中的每个对象都有一个*类型*（type）。函数 `type` 允许我们查看对象的类型。

```python
>>> type(today)
<class 'datetime.date'>
```

到目前为止，我们大量使用过的对象类型相对较少：数字、函数、布尔值，以及现在的日期。我们在第 1 章中也简要遇到过集合和字符串，但还需要更深入地研究它们。还有许多其他种类的对象：声音、图像、位置、网址、网络连接，等等。这些都可以用本章所发展的组合与抽象手段来定义。Python 内建于语言中的原始或*原生*（native）数据类型只有寥寥数种。

原生数据类型具有以下性质：

1. 有一些原始表达式求值为这些类型的对象，称为*字面量*（literal）。
2. 有一些内置函数、运算符和方法来操作这些类型的值。

正如我们所见，数字是原生的；数字字面量求值为数字，数学运算符操作数字对象。

```python
>>> 12 + 3000000000000000000000000
3000000000000000000000012
```

事实上，Python 包含三种原生数值类型：整数（`int`）、实数（`float`）和复数（`complex`）。

```python
>>> type(2)
<class 'int'>
>>> type(1.5)
<class 'float'>
>>> type(1+1j)
<class 'complex'>
```

`float` 这个名字来自实数在 Python 中的表示方式：「浮点」（floating point）表示。数字究竟如何表示并非本书的主题，但了解 `int` 与 `float` 对象之间一些高层次的差异却很重要。特别是，`int` 对象只能表示整数，但它们精确地表示整数，没有任何近似。另一方面，`float` 对象可以表示范围很广的分数，但并非所有有理数都能表示。尽管如此，float 对象常被用来近似表示实数和有理数，精确到某个有效数字位数。
