## 2.3   序列

序列（sequence）是一种有序的数据值集合。与恰好包含两个元素的 pair 不同，一个序列可以拥有任意（但有限）个有序元素。

序列是计算机科学中一个强大而基础的抽象。例如，如果我们有了序列，就可以列出世界上每一所大学，或者每一所大学里的每一位学生。序列抽象支撑着成千上万每天影响着我们生活的数据驱动型程序。

序列并不是某一种特定的抽象数据类型，而是一组不同数据类型所共享的行为集合。也就是说，序列有很多种，但它们都共享某些性质。具体来说，

**长度。** 序列具有有限的长度。

**元素选择。** 对于一个小于序列长度的任意非负整数下标，序列都有一个对应的元素，其中第一个元素的下标为 0。

与抽象数据类型不同，我们并没有说明如何构造一个序列。序列抽象是一组行为的集合，它并不完整地规定一个类型（也就是说不包含构造器与选择器），但可以被多种类型共享。序列提供了一层抽象，从而掩盖了某个特定程序所操作的究竟是哪一种序列类型。

本节中，我们将介绍 Python 内置的、实现了序列抽象的类型。随后我们会自己开发一个能够实现同样抽象的抽象数据类型。

### 2.3.1   元组

事实上，我们为构造原始 pair 而引入的 `tuple` 类型本身就是一个完整的序列类型。与我们用函数式方法实现的 pair 抽象数据类型相比，元组（tuple）提供了多得多的功能。

元组可以有任意长度，并且展现了序列抽象的两个主要行为：长度和元素选择。下面，`digits` 是一个含四个元素的元组。

```python
>>> digits = (1, 8, 2, 8)
>>> len(digits)
4
>>> digits[3]
8
```

此外，元组可以相加，也可以乘以整数。对于元组而言，加法与乘法并不是对元素进行相加或相乘，而是把元组本身进行合并与复制。也就是说，`operator` 模块中的 `add` 函数（以及 `+` 运算符）返回一个新元组，它是两个被加参数的连接。`operator` 中的 `mul` 函数（以及 `*` 运算符）可以接受一个整数 `k` 和一个元组，并返回一个新元组，其中包含该元组参数的 `k` 份副本。

```python
>>> (2, 7) + digits * 2
(2, 7, 1, 8, 2, 8, 1, 8, 2, 8)
```

**多重赋值与多返回值。** 在第 1 章中，我们看到 Python 允许在单条语句中为多个名字赋值。

```python
>>> from math import pi
>>> radius = 10
>>> area, circumference = pi * radius * radius, 2 * pi * radius
>>> area
314.1592653589793
>>> circumference
62.83185307179586
```

我们也可以从函数中返回多个值。

```python
>>> def divide_exact(n, d):
        return n // d, n % d
>>> quotient, remainder = divide_exact(10, 3)
>>> quotient
3
>>> remainder
1
```

实际上，Python 使用元组来表示由逗号分隔的多个值。这被称为*元组打包（tuple packing）*。

```python
>>> digits = 1, 8, 2, 8
>>> digits
(1, 8, 2, 8)
>>> divide_exact(10, 3)
(3, 1)
```

用一个元组为多个名字赋值，正如人们所料，被称为*元组解包（tuple unpacking）*。这些名字可以被圆括号包围，也可以不加圆括号。

```python
>>> d0, d1, d2, d3 = digits
>>> d2
2
>>> (quotient, remainder) = divide_exact(10, 3)
>>> quotient
3
>>> remainder
1
```

多重赋值不过是元组打包与元组解包的结合。

**任意参数列表。** 元组可以用来定义接受任意数量参数的函数，例如内置的 `print` 函数。我们在参数名前加一个 `*`，来表示可以为该参数传入任意数量的实参。Python 会自动把这些实参打包成一个元组，并把参数名绑定到该元组上。

```python
>>> def add_all(*args):
        """Compute the sum of all arguments."""
        total, index = 0, 0
        while index < len(args):
            total = total + args[index]
            index = index + 1
        return total
```

```python
>>> add_all(1, 3, 2)
6
```

此外，我们还可以用 `*` 运算符来解包一个元组，从而把它的各个元素作为独立的实参传给函数调用。

```python
>>> pow(*(2, 3))
8
```

如这些例子所示，元组支持我们在 Python 中一直在使用的许多特性。

### 2.3.2   序列迭代

在很多情况下，我们希望遍历一个序列的元素，并依次对每个元素执行一个计算过程。这种模式如此常见，以至于 Python 提供了一条额外的控制语句来处理顺序数据：`for` 语句。

考虑这样一个问题：统计某个值在一个序列中出现了多少次。我们可以用 `while` 循环来实现一个计算该次数的函数。

```python
>>> def count(s, value):
        """Count the number of occurrences of value in sequence s."""
        total, index = 0, 0
        while index < len(s):
            if s[index] == value:
                total = total + 1
            index = index + 1
        return total
```

```python
>>> count(digits, 8)
2
```

Python 的 `for` 语句可以直接遍历元素值，从而简化这个函数体，完全不必引入名字 `index`。

```python
>>> def count(s, value):
        """Count the number of occurrences of value in sequence s."""
        total = 0
        for elem in s:
            if elem == value:
                total = total + 1
        return total
```

```python
>>> count(digits, 8)
2
```

一条 `for` 语句由单个子句构成，其形式为：

```python
for <name> in <expression>:
    <suite>
```

`for` 语句按以下过程执行：

1. 求值头部中的 `<expression>`，它必须产生一个可迭代的值。
2. 按顺序对该序列中的每个元素值：
在局部环境中把 `<name>` 绑定到该值。
执行 `<suite>`。

第 1 步提到了可迭代的值。序列是可迭代的，它们的元素按其顺序依次被考虑。Python 确实还包含其他可迭代类型，但目前我们只关注序列；"可迭代"（iterable）这一术语的一般定义出现在第 4 章关于迭代器的小节中。

这一求值过程的一个重要结果是，在 `for` 语句执行完毕后，`<name>` 会绑定到序列的最后一个元素上。`for` 循环为语句更新局部环境又引入了一种新的方式。

**序列解包。** 程序中的一种常见模式是：拥有一个元素本身也是序列的序列，而所有这些内层序列都有固定的长度。`For` 语句可以在其头部包含多个名字，从而把每个元素序列"解包"成各自对应的元素。例如，我们可能有一个由 pair（也就是二元元组）组成的序列，

```python
>>> pairs = ((1, 2), (2, 2), (2, 3), (4, 4))
```

并希望找出第一个元素与第二个元素相同的 pair 的个数。

```python
>>> same_count = 0
```

下面这条在头部含有两个名字的 `for` 语句，会把名字 `x` 和 `y` 分别绑定到每一对中的第一个元素和第二个元素上。

```python
>>> for x, y in pairs:
        if x == y:
            same_count = same_count + 1
```

```python
>>> same_count
2
```

这种把一个固定长度序列中的多个值绑定到多个名字上的模式，被称为*序列解包（sequence unpacking）*；它与我们在把多个值绑定到多个名字的赋值语句中所看到的模式相同。

**范围。** `range` 是 Python 中另一种内置的序列类型，它表示一个整数范围。范围由 `range` 创建，它接受两个整数参数：起始数字，以及所需范围中最后一个数字之后的那个数。

```python
>>> range(1, 10)  # Includes 1, but not 10
range(1, 10)
```

对一个 range 调用 `tuple` 构造器，会创建出一个与其元素相同的元组，从而可以方便地查看这些元素。

```python
>>> tuple(range(5, 8))
(5, 6, 7)
```

如果只给出一个参数，它会被解释为从一个以 0 起始的范围中最后一个值之后的那个数。

```python
>>> tuple(range(4))
(0, 1, 2, 3)
```

range 常常作为 `for` 头部中的表达式出现，用来指定该子句体应当执行的次数：

```python
>>> total = 0
>>> for k in range(5, 8):
        total = total + k
```

```python
>>> total
18
```

一个常见的惯例是：如果在子句体中不使用 `for` 头部里的那个名字，就用单个下划线字符作为它的名字：

```python
>>> for _ in range(3):
        print('Go Bears!')

Go Bears!
Go Bears!
Go Bears!
```

就解释器而言，这个下划线不过是环境中的另一个名字，但它在程序员之间有约定俗成的含义，表示这个名字不会出现在任何表达式中。

### 2.3.3   序列抽象

我们现在已经介绍了两种实现了序列抽象的内置数据类型：元组与 range。它们都满足本节开头的那些条件：长度和元素选择。Python 还包含另外两种扩展了序列抽象的序列类型行为。

**成员资格。** 可以测试某个值是否属于某个序列。Python 有两个运算符 `in` 和 `not in`，它们根据一个元素是否出现在序列中而求值为 `True` 或 `False`。

```python
>>> digits
(1, 8, 2, 8)
>>> 2 in digits
True
>>> 1828 not in digits
True
```

所有序列还都有名为 `index` 和 `count` 的方法，它们返回某个值在序列中的下标（或出现次数）。

**切片。** 序列内部包含更小的序列。序列的一个*切片（slice）*是原序列中任意一段连续的范围，由一对整数指定。与 `range` 构造器一样，第一个整数表示切片的起始下标，第二个整数表示结束下标之后的那个位置。

在 Python 中，序列切片的表示方式与元素选择类似，使用方括号。一个冒号将起始下标与结束下标分隔开。任何被省略的边界都假定为极值：起始下标默认为 0，结束下标默认为序列的长度。

```python
>>> digits[0:2]
(1, 8)
>>> digits[1:]
(8, 2, 8)
```

列举 Python 序列抽象的这些附加行为，给了我们一个机会去反思：一般而言，什么才构成了一个有用的数据抽象。一个抽象的丰富程度（也就是它包含多少种行为）是有后果的。对于抽象的使用者而言，附加的行为可能有帮助。另一方面，用一种新的数据类型去满足一个丰富抽象的各项要求，可能会很有挑战。丰富抽象的另一个负面后果是，使用者需要花更长时间去学习。

序列之所以拥有丰富的抽象，是因为它们在计算中无处不在，因此花力气学习一些复杂行为是值得的。一般而言，大多数用户自定义的抽象都应当尽可能保持简单。

**延伸阅读。** 切片表示法允许各种特殊情况，例如负的起始值、结束值和步长。完整的描述出现在 Dive Into Python 3 中名为 [slicing a list](http://getpython3.com/diveintopython3/native-datatypes.html#slicinglists) 的小节里。本章中，我们只会使用上面描述的基本特性。

### 2.3.4   嵌套 pair

对于有理数，我们用二元元组把两个整数对象配对起来，随后又展示了我们完全可以用函数来实现 pair。在那种情况下，我们构造的每一对元素都是整数。然而，与表达式一样，元组也可以嵌套。一个 pair 的任一元素本身都可以是一个 pair，这一点对于我们见过的两种实现 pair 的方法（用元组实现，或用分派函数实现）都成立。

我们用*盒指针（box-and-pointer）*表示法在环境图中可视化 pair（二元元组）。pair 被描绘成分为两部分的盒子：左半部分包含（一个指向）该 pair 第一个元素的箭头，右半部分包含第二个元素。诸如数字、字符串、布尔值和 `None` 之类的简单值直接出现在盒子中。诸如函数值和其他 pair 之类的复合值则通过指针连接。

```python
numbers = (1, 2)
pairs = ((1, 2), (3, 4))
```

我们可以用递归来处理任意深度的 pair 嵌套。例如，让我们写一个函数，计算一个由 pair 与整数嵌套而成的结构中所有整数元素之和。

```python
def sum_elems(elem):
    if type(elem) == int:
        return elem
    else:
        return (sum_elems(elem[0]) +
                sum_elems(elem[1]))

pairs = ((1, 2), (3, 4))
total = sum_elems(pairs)
```

`sum_elems` 函数通过递归地计算嵌套 pair 的第一个和第二个元素之和并相加，来计算其中整数元素之和。基例是当某个元素为整数时，此时和就是该整数本身。

我们把元组用作其他元组的元素的能力，为我们的编程语言提供了一种新的组合手段。我们把元组能够这样嵌套的能力称为元组数据类型的*闭包性质（closure property）*。一般而言，如果某种组合数据值的方法所产生的结果本身还能用同样的方法继续组合，那么这种方法就满足闭包性质。闭包是任何组合手段之所以强大的关键，因为它允许我们创建层次结构——由部件构成的结构，而这些部件本身又由更小的部件构成，以此类推。我们将在第 3 章探索一系列层次结构。现在，我们先考虑一种特别重要的结构。

### 2.3.5   递归链表

我们可以用嵌套 pair 来构造任意长度元素组成的链表，这将使我们能够实现序列抽象。下面的环境图展示了一个四元素链表 1, 2, 3, 4 的递归表示的结构。

```python
up_to_four = (1, (2, (3, (4, None))))
```

该链表由一条 pair 链表示。每个 pair 的第一个元素是链表中的一个元素，而第二个元素是表示链表其余部分的 pair。最后一个 pair 的第二个元素是 `None`，表示链表已经结束。这一结构可以用上面的嵌套元组字面量来构造。

这种嵌套结构对应于一种思考序列的非常有用的方式。一个非空序列可以被分解为：

- 它的第一个元素，以及
- 序列的其余部分。

序列的其余部分本身也是一个（可能为空的）序列。我们把这种关于序列的观点称为递归的，因为序列把其他序列作为自己的第二个组成部分。

由于我们的链表表示是递归的，为了不把它与 Python 中我们稍后会讨论的内置 `list` 类型相混淆，我们在实现中把它称为 `rlist`。一个递归链表（recursive list）可以由第一个元素和链表的其余部分构造而成。值 `None` 表示一个空的递归链表。

```python
>>> empty_rlist = None
>>> def rlist(first, rest):
        """Construct a recursive list from its first element and the rest."""
        return (first, rest)
```

```python
>>> def first(s):
        """Return the first element of a recursive list s."""
        return s[0]
```

```python
>>> def rest(s):
        """Return the rest of the elements of a recursive list s."""
        return s[1]
```

这两个选择器、一个构造器和一个常量一起实现了递归链表抽象数据类型。递归链表的唯一一个行为条件是：与 pair 一样，它的构造器与选择器互为逆函数。

- 如果一个递归链表 `s` 是由元素 `f` 和链表 `r` 构造出来的，
那么 `first(s)` 返回 `f`，而 `rest(s)` 返回 `r`。

我们可以用构造器与选择器来操作递归链表。

```python
>>> counts = rlist(1, rlist(2, rlist(3, rlist(4, empty_rlist))))
>>> first(counts)
1
>>> rest(counts)
(2, (3, (4, None)))
```

回想一下，我们能够用函数来表示 pair，因此我们同样可以用函数来表示递归链表。

递归链表可以按顺序存储一串值，但它还没有实现序列抽象。利用我们定义的抽象数据类型，我们可以实现刻画序列的两个行为：长度和元素选择。

```python
>>> def len_rlist(s):
        """Return the length of recursive list s."""
        length = 0
        while s != empty_rlist:
            s, length = rest(s), length + 1
        return length
```

```python
>>> def getitem_rlist(s, i):
        """Return the element at index i of recursive list s."""
        while i > 0:
            s, i = rest(s), i - 1
        return first(s)
```

现在，我们可以把递归链表当作序列来操作了：

```python
>>> len_rlist(counts)
4
>>> getitem_rlist(counts, 1)  # The second item has index 1
2
```

这两个实现都是迭代式的。它们一层层地剥开嵌套 pair，直到到达链表的末尾（在 `len_rlist` 中）或期望的元素（在 `getitem_rlist` 中）。我们也可以用递归来实现长度和元素选择。

```python
>>> def len_rlist_recursive(s):
        """Return the length of a recursive list s."""
        if s == empty_rlist:
            return 0
        return 1 + len_rlist_recursive(rest(s))
```

```python
>>> def getitem_rlist_recursive(s, i):
        """Return the element at index i of recursive list s."""
        if i == 0:
            return first(s)
        return getitem_rlist_recursive(rest(s), i - 1)
```

```python
>>> len_rlist_recursive(counts)
4
>>> getitem_rlist_recursive(counts, 1)
2
```

这些递归实现沿着 pair 链前进，直到到达链表的末尾（在 `len_rlist_recursive` 中）或期望的元素（在 `getitem_rlist_recursive` 中）。

递归链表既可以用迭代操作，也可以用递归操作。不过在第 3 章中，我们会看到更复杂的递归数据结构示例，它们需要用递归才能方便地操作。

让我们回到用迭代方式实现长度和元素选择。下面一系列环境图展示了 `getitem_rlist` 在递归链表中找到下标 1 处的元素 2 的迭代过程。在下面，我们用 Python 原语定义了 rlist `counts`，以简化图示。这一实现选择违背了 rlist 数据类型的抽象屏障，但让我们在这个例子中更容易地考察计算过程。

```python
def first(s):
    return s[0]
def rest(s):
    return s[1]

def getitem_rlist(s, i):
    while i > 0:
        s, i = rest(s), i - 1
    return first(s)

counts = (1, (2, (3, (4, None))))
getitem_rlist(counts, 1)
```

首先，函数 `getitem_rlist` 被调用，创建一个局部帧。

```python
def first(s):
    return s[0]
def rest(s):
    return s[1]

def getitem_rlist(s, i):
    while i > 0:
        s, i = rest(s), i - 1
    return first(s)

counts = (1, (2, (3, (4, None))))
getitem_rlist(counts, 1)
```

`while` 头部中的表达式求值为真，这导致 `while` 子句体中的赋值语句被执行。函数 `rest` 返回从 2 开始的子链表。

```python
def first(s):
    return s[0]
def rest(s):
    return s[1]

def getitem_rlist(s, i):
    while i > 0:
        s, i = rest(s), i - 1
    return first(s)

counts = (1, (2, (3, (4, None))))
getitem_rlist(counts, 1)
```

接下来，局部名字 `s` 会被更新为指向从原链表第二个元素开始的子链表。此时求值 `while` 头部表达式得到一个假值，于是 Python 求值 `getitem_rlist` 最后一行 return 语句中的表达式。

```python
def first(s):
    return s[0]
def rest(s):
    return s[1]

def getitem_rlist(s, i):
    while i > 0:
        s, i = rest(s), i - 1
    return first(s)

counts = (1, (2, (3, (4, None))))
getitem_rlist(counts, 1)
```

最后这张环境图展示了调用 `first` 时的局部帧，其中包含绑定到同一个子链表的名字 `s`。`first` 函数选出值 2 并返回它，这个值也会从 `getitem_rlist` 中返回。

这个例子展示了一种用递归链表进行计算的常见模式：迭代中的每一步都操作原链表中越来越短的后缀。这种为找到递归链表的长度与元素而进行的逐步处理确实需要花一些计算时间。（在第 3 章中，我们将学会刻画这类迭代函数的计算时间。）Python 内置的序列类型是以一种不同的方式实现的，因此在计算序列长度或取出其元素时不会有很大的计算开销。

我们构造递归链表的方式相当繁琐。幸运的是，Python 提供了多种内置序列类型，它们既具备序列抽象的多功能性，又提供了便捷的表示法。

### 2.3.6   字符串

文本值对计算机科学来说也许比数字更为基础。举例来说，Python 程序本身就是以文本形式书写和存储的。Python 中用于文本的原生数据类型称为字符串（string），它对应于构造器 `str`。

关于字符串在 Python 中如何表示、书写和操作，有许多细节。字符串是另一个丰富抽象的例子，要掌握它需要程序员付出相当大的努力。本节对字符串的基本行为做一个浓缩的介绍。

字符串字面量可以表示任意文本，由单引号或双引号包围。

```python
>>> 'I am string!'
'I am string!'
>>> "I've got an apostrophe"
"I've got an apostrophe"
>>> '您好'
'您好'
```

我们已经在代码中见过字符串了，它们出现在文档字符串里、`print` 调用中，以及 `assert` 语句的错误消息里。

字符串满足我们在本节开头介绍的序列的两个基本条件：它们有长度，并且支持元素选择。

```python
>>> city = 'Berkeley'
>>> len(city)
8
>>> city[3]
'k'
```

字符串的元素本身也是字符串，只不过只含单个字符。一个字符可以是字母表中的任意单个字母、标点符号或其他符号。与许多其他编程语言不同，Python 没有单独的字符类型；任何文本都是字符串，而表示单个字符的字符串长度为 1。

与元组一样，字符串也可以相加和相乘。

```python
>>> 'Berkeley' + ', CA'
'Berkeley, CA'
>>> 'Shabu ' * 2
'Shabu Shabu '
```

**成员资格。** 字符串的行为与 Python 中其他序列类型不同。字符串抽象并不完全符合我们为元组和 range 所描述的那套完整序列抽象。特别是，成员资格运算符 `in` 适用于字符串，但其行为与应用到序列上时完全不同。它匹配的是子串而不是元素。

```python
>>> 'here' in "Where's Waldo?"
True
```

同样地，字符串上的 `count` 和 `index` 方法接受子串作为参数，而不是单字符元素。`count` 的行为尤其微妙；它统计一个子串在字符串中不重叠出现的次数。

```python
>>> 'Mississippi'.count('i')
4
>>> 'Mississippi'.count('issi')
1
```

**多行字面量。** 字符串并不局限于单行。三引号限定的字符串字面量可以跨越多行。我们已经大量使用这种三引号写法来书写文档字符串了。

```python
>>> """The Zen of Python
claims, Readability counts.
Read more: import this."""
'The Zen of Python\nclaims, "Readability counts."\nRead more: import this.'
```

在上面的打印结果中，`\n`（读作"*反斜杠 n*"）是一个表示换行的单个元素。尽管它看起来像两个字符（反斜杠和字母 n），但在长度和元素选择的意义上，它被视为单个字符。

**字符串强制转换。** 可以通过以某个对象值为实参调用 `str` 构造器函数，从 Python 中的任意对象创建字符串。字符串的这一特性对于从各种类型的对象构造描述性字符串很有用。

```python
>>> str(2) + ' is an element of ' + str(digits)
'2 is an element of (1, 8, 2, 8)'
```

单个 `str` 函数能够适用于任意类型的实参并返回一个恰当的值，其背后的机制是后面关于泛型函数的小节的主题。

**方法。** Python 中字符串的行为之所以极为丰富，是因为它有一大批用于返回字符串变体和搜索内容的方法。下面通过示例介绍其中几个方法。

```python
>>> '1234'.isnumeric()
True
>>> 'rOBERT dE nIRO'.swapcase()
'Robert De Niro'
>>> 'snakeyes'.upper().endswith('YES')
True
```

**延伸阅读。** 在计算机中编码文本是一个复杂的话题。本章中，我们将把字符串如何表示的细节抽象掉。然而对于许多应用来说，字符串在计算机中如何编码的具体细节是必不可少的知识。[Dive Into Python 3 的 4.1-4.3 节](http://getpython3.com/diveintopython3/strings.html)描述了字符编码与 Unicode。

### 2.3.7   序列处理

序列是一种如此常见的复合数据形式，以至于人们常常围绕着这一个抽象来组织整个程序。把程序中的所有数据都表示为序列，使我们能够开发出可以相互搭配使用的模块化组件来完成数据处理。也就是说，我们可以编写若干函数，它们都接受一个序列作为参数并返回一个序列作为值，然后我们可以按任意顺序把每一个函数应用到下一个函数的输出上。这样，我们就能通过把一条由函数组成的流水线衔接起来，创造出复杂的处理过程，而其中每个函数都简单而专注。

有两种通用的序列操作构成了许多数据处理的基础：`map` 和 `filter`。

**Map。** 一种强大的序列变换方法是对每个元素应用一个函数并收集结果。这种通用的计算形式称为把一个函数*映射（mapping）*到一个序列上，对应于内置的 `map`。调用 `map` 的结果是一个对象，它本身并不是序列，但可以通过调用 `tuple`（元组的构造器函数）把它转换成一个序列。这个结果也可以被传入其他序列处理操作中。

```python
>>> alternates = (-1, 2, -3, 4, -5)
>>> tuple(map(abs, alternates))
(1, 2, 3, 4, 5)
```

映射之所以重要，是因为它依赖于序列抽象：我们不必关心底层元组的结构，只需关心我们能够按顺序单独访问它的每一个元素，以便将其作为实参传给被映射的函数（在这个例子中是 `abs`）。其他类型的序列（稍后介绍）也可以作为 `map` 的第二个实参。

**Filter。** `filter` 也是 Python 内置的；它接受一个序列，并返回该序列中使某个谓词为真的那些元素。

```python
>>> nums = (5, 6, -7, -8, 9)
>>> def even(n):
        return n % 2 == 0
>>> tuple(filter(even, nums))
(6, -8)
```

序列操作也可以嵌套。

```python
>>> sum(filter(even, map(abs, nums)))
14
```

考虑下面两个问题，它们乍看起来只是在用到序列这一点上相关：

1. 求前 `n` 个斐波那契数中偶数成员之和。
2. 列出一个名字的首字母缩写中的各个字母，其中包含每个首字母大写单词的第一个字母。

这两个问题之所以相关，是因为它们都可以被分解为若干简单操作，这些操作以序列为输入并产生序列作为输出。而且，这些操作都是对序列进行计算的通用方法的实例。让我们考虑第一个问题。它可以被分解为以下几个步骤：

```python
 enumerate     map    filter  accumulate
-----------    ---    ------  ----------
naturals(n)    fib     even      sum
```

下面这个 `fib` 函数计算斐波那契数（现在它已从第 1 章中的定义更新为使用 `for` 语句的形式），

```python
>>> def fib(k):
        """Compute the kth Fibonacci number."""
        prev, curr = 1, 0  # curr is the first Fibonacci number.
        for _ in range(k - 1):
             prev, curr = curr, prev + curr
        return curr
```

现在我们可以用 `map`、`filter` 和 `sum` 来实现 `even_fib`，也就是第一个问题的解。谓词 `even` 已在本节前面定义过了。

```python
>>> def sum_even_fibs(n):
        """Sum the even members of the firsT n Fibonacci numbers."""
        return sum(filter(even, map(fib, range(1, n+1))))
```

```python
>>> sum_even_fibs(20)
3382
```

现在，让我们考虑第二个问题。它同样可以被分解为一条包含 `map` 和 `filter` 的序列操作流水线：

```python
enumerate     filter     map   accumulate
---------  -----------  -----  ----------
  words    capitalized  first    tuple
```

字符串中的单词可以通过字符串对象的 `split` 方法来枚举，它默认按空格进行分割。

```python
>>> tuple('Spaces between words'.split())
('Spaces', 'between', 'words')
```

一个单词的第一个字母可以用选择运算符取得，而判断一个单词是否首字母大写的谓词可以用内置谓词 `isupper` 来定义。

```python
>>> def first(s):
        return s[0]
```

```python
>>> def capitalized(s):
        return len(s) > 0 and s[0].isupper()
```

至此，我们的首字母缩写函数可以用 `map` 和 `filter` 来定义了。

```python
>>> def acronym(name):
        """Return a tuple of the letters that form the acronym for name."""
        return tuple(map(first, filter(capitalized, name.split())))
```

```python
>>> acronym('University of California Berkeley Undergraduate Graphics Group')
('U', 'C', 'B', 'U', 'G', 'G')
```

这些解决相当不同问题的相似方案，展示了如何利用映射、过滤和累积这些通用计算模式，把作用于序列的通用组件组合起来。序列抽象使我们能够简洁地表述这些解。

把程序表达为序列操作，有助于我们设计模块化的程序。我们的设计是通过组合相对独立的部件构造出来的，每个部件都变换一个序列。一般而言，我们可以通过提供一个标准组件库，再加上一个关于数据表示的假设（例如所有输入和输出都是序列），来鼓励模块化设计。

**生成器表达式。** Python 语言还包含第二种处理序列的方法，称为*生成器表达式（generator expressions）*，它提供的功能与 `map` 和 `filter` 类似，但可能需要的函数定义更少。

生成器表达式把过滤与映射的思想结合成一种单一的表达式类型，其形式如下：

```python
<map expression> for <name> in <sequence expression> if <filter expression>
```

要求值一个生成器表达式，Python 先求值 `<sequence expression>`，它必须返回一个可迭代的值。然后，按顺序对每个元素，把该元素值绑定到 `<name>`，求值过滤表达式，如果它产生真值，则求值映射表达式。

求值生成器表达式所得到的结果值本身也是一个可迭代的值。诸如 `tuple`、`sum`、`max` 和 `min` 之类的累积函数可以接受这个返回的对象作为实参。

```python
>>> def acronym(name):
        return tuple(w[0] for w in name.split() if capitalized(w))
```

```python
>>> def sum_even_fibs(n):
        return sum(fib(k) for k in range(1, n+1) if fib(k) % 2 == 0)
```

生成器表达式是用于序列处理的专门语法。这些表达式涵盖了 `map` 和 `filter` 的大部分功能，但避免了实际创建被应用的函数值（也顺带避免了创建应用这些函数所需的环境帧）。

**Reduce。** 在我们的例子中，我们使用特定的函数来累积结果，或是 `tuple`，或是 `sum`。函数式编程语言（包括 Python）都包含通用高阶累积函数，它们有各种不同的名字。Python 在 `functools` 模块中包含 `reduce`，它把一个接受两个参数的函数从左到右累积地应用到序列的元素上，从而把一个序列归约成一个值。下面这个表达式计算 5 的阶乘。

```python
>>> from operator import mul
>>> from functools import reduce
>>> reduce(mul, (1, 2, 3, 4, 5))
120
```

使用这种更一般的累积形式，我们同样可以用序列处理技术来计算偶数斐波那契数之积，而不仅是求和。

```python
>>> def product_even_fibs(n):
        """Return the product of the first n even Fibonacci numbers, except 0."""
        return reduce(mul, filter(even, map(fib, range(2, n+1))))
```

```python
>>> product_even_fibs(20)
123476336640
```

对应于 `map`、`filter` 和 `reduce` 的高阶过程的组合，将在第 4 章中再次出现，届时我们将考虑把计算分发到多台计算机上的方法。
