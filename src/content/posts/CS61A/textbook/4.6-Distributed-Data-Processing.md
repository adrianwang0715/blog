## 4.6   分布式数据处理

分布式系统常被用来收集、访问和操作大型数据集。例如，本章前面介绍过的数据库系统可以运行在跨多台机器存储的数据集之上。可能没有任何单台机器包含响应某个查询所需的数据，因此需要通信才能服务于请求。

本节考察一个典型的大数据处理场景：一个太大而无法由单台机器处理的数据集，转而分布在许多机器之间，每台机器处理数据集的一部分。处理的结果往往必须跨机器聚合，以便把一台机器计算的结果与其他机器的结果结合起来。为了协调这种分布式数据处理，我们将讨论一个名为 [MapReduce](http://en.wikipedia.org/wiki/MapReduce) 的编程框架。

用 MapReduce 创建分布式数据处理应用，综合了本书通篇介绍的许多思想。一个应用以纯函数来表达，这些纯函数先用于在一个大型数据集上*映射*（map），然后把映射后的值序列*归约*（reduce）为最终结果。

函数式编程中熟悉的概念在 MapReduce 程序中得到了最大程度的运用。MapReduce 要求用于映射和归约数据的函数必须是纯函数。一般而言，仅用纯函数表达的程序在其执行方式上具有相当的灵活性。子表达式可以按任意顺序、并行地求值，而不会影响最终结果。MapReduce 应用会并行地求值许多纯函数，对计算进行重新排序，以便在分布式系统中高效执行。

MapReduce 的主要优点在于，它在分布式数据处理应用的两个部分之间强制实现了关注点分离：

1. 处理数据并合并结果的 map 和 reduce 函数。
2. 机器之间的通信与协调。

协调机制处理分布式计算中出现的许多问题，例如机器故障、网络故障和进度监控。尽管管理这些问题会给 MapReduce 应用带来一些复杂性，但这些复杂性都不会暴露给应用开发者。相反，构建 MapReduce 应用只需要指定上面第 (1) 项中的 map 和 reduce 函数即可；分布式计算的种种挑战都通过抽象被隐藏了起来。

### 4.6.1   MapReduce

MapReduce 框架假定输入是一个大型、无序的数据流，其中的值为任意类型。例如，每个输入可以是某个庞大语料库中的一行文本。计算分三步进行。

1. 对每个输入应用一个 map 函数，它输出零个或多个任意类型的中间键值对（key-value pair）。
2. 所有中间键值对按键分组，以便具有相同键的键值对可以一起被归约。
3. 一个 reduce 函数合并给定键 `k` 对应的值；它输出零个或多个值，每个值在最终输出中都关联到 `k`。

为执行这一计算，MapReduce 框架会创建若干任务（可能位于不同的机器上），这些任务在计算中扮演各种角色。*map 任务*（map task）把 map 函数应用于输入数据的某个子集，并输出中间键值对。*reduce 任务*按键对键值对排序和分组，然后对每个键的值应用 reduce 函数。map 任务与 reduce 任务之间的所有通信都由框架处理，按键对中间键值对进行分组这一任务同样由框架处理。

为了在 MapReduce 应用中利用多台机器，多个 mapper 在一个*映射阶段*（map phase）并行运行，多个 reducer 在一个*归约阶段*（reduce phase）并行运行。在这两个阶段之间，*排序阶段*（sort phase）通过对键值对排序把它们分组，使得所有具有相同键的键值对都相邻。

考虑统计文本语料库中元音数量的问题。我们可以借助 MapReduce 框架，通过恰当地选择 map 和 reduce 函数来解决这个问题。map 函数以一个文本行作为输入，输出若干键值对，其中键是一个元音，值是一个计数。计数为零的会被省略，不出现在输出中：

```python
def count_vowels(line):
    """A map function that counts the vowels in a line."""
    for vowel in 'aeiou':
        count = line.count(vowel)
        if count > 0:
            emit(vowel, count)
```

reduce 函数就是 Python 内置的 sum 函数，它以值的迭代器（某个给定键的所有值）作为输入，并返回它们的和。

### 4.6.2   本地实现

要指定一个 MapReduce 应用，我们需要一个 MapReduce 框架的实现，以便把 map 和 reduce 函数插入其中。在下一节中，我们将使用开源的 [Hadoop](http://en.wikipedia.org/wiki/Hadoop) 实现。在本节中，我们用 Unix 操作系统的内置工具开发一个最小实现。

Unix 操作系统在用户程序与计算机底层硬件之间创建了一道抽象屏障。它提供了一种让程序相互通信的机制，特别是允许一个程序消费另一个程序的输出。在其关于 Unix 编程的开创性著作中，Kernigham 和 Pike 断言："一个系统的能力更多来自程序之间的关系，而非程序本身。"

只需在首行添加一条注释，指明该程序应使用 Python 3 解释器执行，就可以把一个 Python 源文件转换为一个 Unix 程序。Unix 程序的输入是一个称为*标准输入*（standard input）的可迭代对象，通过 `sys.stdin` 访问。迭代这个对象会逐行产出字符串形式的文本。Unix 程序的输出称为*标准输出*（standard output），通过 `sys.stdout` 访问。内置的 `print` 函数向标准输出写入一行文本。下面的 Unix 程序把其输入的每一行反转后写到输出：

```python
#!/usr/bin/env python3

import sys

for line in sys.stdin:
    print(line.strip('\n')[::-1])
```

如果我们把这个程序保存到一个名为 `rev.py` 的文件中，就可以把它作为一个 Unix 程序来执行。首先，我们需要告诉操作系统我们创建了一个可执行程序：

```bash
$ chmod u+x rev.py
```

接下来，我们可以把输入传进这个程序。程序的输入可以来自另一个程序。这一效果借助 `|` 符号（称为"管道"）实现，它把管道之前的程序的输出导入到管道之后的程序中。程序 `nslookup` 输出某个 IP 地址的主机名（此例中是《纽约时报》）：

```bash
$ nslookup 170.149.172.130 | ./rev.py
moc.semityn.www
```

`cat` 程序输出文件的内容。因此，`rev.py` 程序可以用来反转 `rev.py` 文件的内容：

```bash
$ cat rev.py | ./rev.py
3nohtyp vne/nib/rsu/!#

sys tropmi

:nidts.sys ni enil rof
)]1-::[)'n\'(pirts.enil(tnirp
```

这些工具足以让我们实现一个基本的 MapReduce 框架。这个版本只有一个 map 任务和一个 reduce 任务，它们都是用 Python 实现的 Unix 程序。我们用以下命令运行一个完整的 MapReduce 应用：

```bash
$ cat input | ./mapper.py | sort | ./reducer.py
```

`mapper.py` 和 `reducer.py` 程序必须实现 map 函数和 reduce 函数，以及一些简单的输入和输出行为。例如，为了实现上面描述的元音计数应用，我们会编写如下 `count_vowels_mapper.py` 程序：

```python
#!/usr/bin/env python3

import sys
from mr import emit

def count_vowels(line):
    """A map function that counts the vowels in a line."""
    for vowel in 'aeiou':
        count = line.count(vowel)
        if count > 0:
            emit(vowel, count)

for line in sys.stdin:
    count_vowels(line)
```

此外，我们会编写如下 `sum_reducer.py` 程序：

```python
#!/usr/bin/env python3

import sys
from mr import values_by_key, emit

for key, value_iterator in values_by_key(sys.stdin):
    emit(key, sum(value_iterator))
```

[mr 模块](../examples/mapreduce/mr.py)是本书配套模块，它提供了 `emit` 函数用于发出一个键值对，以及 `group_values_by_key` 用于把具有相同键的值分组。该模块还包含一个通往 MapReduce 的 Hadoop 分布式实现的接口。

最后，假定我们有如下名为 `haiku.txt` 的输入文件：

```python
Google MapReduce
Is a Big Data framework
For batch processing
```

使用 Unix 管道进行本地执行，就得到了这首俳句中每个元音的数量：

```bash
$ cat haiku.txt | ./count_vowels_mapper.py | sort | ./sum_reducer.py
'a'   6
'e'   5
'i'   2
'o'   5
'u'   1
```

### 4.6.3   分布式实现

[Hadoop](http://en.wikipedia.org/wiki/Hadoop) 是 MapReduce 框架的一个开源实现的名称，它在机器集群上执行 MapReduce 应用，分布输入数据和计算以实现高效的并行处理。它的流式接口允许用任意的 Unix 程序来定义 map 和 reduce 函数。事实上，我们的 `count_vowels_mapper.py` 和 `sum_reducer.py` 可以直接配合 Hadoop 安装使用，在大型文本语料库上计算元音数量。

相比我们那个简陋的本地 MapReduce 实现，Hadoop 提供了若干优势。第一是速度：map 和 reduce 函数在不同的机器上、由同时运行的不同任务并行地应用。第二是容错：当一个任务因任何原因失败时，其结果可以由另一个任务重新计算，以完成整体计算。第三是监控：该框架提供了一个用户界面来跟踪 MapReduce 应用的进度。

为了使用所提供的 `mapreduce.py` 模块运行元音计数应用，请安装 Hadoop，把 `HADOOP` 的赋值语句改为你本地安装的根目录，把一批文本文件复制进 Hadoop 分布式文件系统，然后运行：

```bash
$ python3 mr.py run count_vowels_mapper.py sum_reducer.py [input] [output]
```

其中 `[input]` 和 `[output]` 是 Hadoop 文件系统中的目录。

关于 Hadoop 流式接口及该系统用法的更多信息，请查阅 [Hadoop Streaming 文档](http://hadoop.apache.org/docs/stable/streaming.html)。
