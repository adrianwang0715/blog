## 2.6   实现类与对象

在使用面向对象编程范式时，我们用对象隐喻来指导程序的组织。关于如何表示和操作数据的大部分逻辑，都表达在类声明之中。在本节中，我们将看到，类和对象本身也可以仅用函数和字典来表示。以这种方式实现对象系统的目的，是为了说明使用对象隐喻并不需要一门特殊的编程语言。即使在没有内置对象系统的编程语言中，程序也可以是面向对象的。

为了实现对象，我们将放弃点号标记（它确实需要内置的语言支持），转而创建行为与内置对象系统各元素大体相同的派发字典。我们已经看到如何通过派发字典实现消息传递行为。要实现一个完整的对象系统，我们在实例、类和基类之间传递消息，它们全都是包含属性的字典。

我们不会实现整个 Python 对象系统，其中包含本书未曾涉及的特性（例如元类和静态方法）。我们将聚焦于没有多重继承、也没有内省行为（例如返回某个实例所属的类）的用户自定义类。我们的实现并不打算遵循 Python 类型系统的精确规范，而是旨在实现支撑对象隐喻的核心功能。

### 2.6.1   实例

我们从实例开始。实例拥有具名属性，比如账户的余额，这些属性可以被设置和获取。我们用一个派发字典来实现实例，它响应"获取"和"设置"属性值的消息。属性本身存储在一个名为 `attributes` 的局部字典中。

正如本章前面所见，字典本身就是抽象数据类型。我们用列表实现字典，用对（pair）实现列表，又用函数实现对。当我们用字典来实现对象系统时，请记住：我们完全可以只用函数来实现对象。

在开始实现时，我们假定已经有一个类的实现，它能够查找任何不属于该实例的名称。我们把一个类作为参数 `cls` 传入 `make_instance`。

```python
>>> def make_instance(cls):
        """Return a new object instance, which is a dispatch dictionary."""
        def get_value(name):
            if name in attributes:
                return attributes[name]
            else:
                value = cls['get'](name)
                return bind_method(value, instance)
        def set_value(name, value):
            attributes[name] = value
        attributes = {}
        instance = {'get': get_value, 'set': set_value}
        return instance
```

`instance` 是一个派发字典，它响应消息 `get` 和 `set`。`set` 消息对应于 Python 对象系统中的属性赋值：所有被赋值的属性都直接存储在对象本地的属性字典中。在 `get` 中，如果 `name` 没有出现在本地 `attributes` 字典中，那么就在类中查找它。如果 `cls` 返回的 `value` 是一个函数，它就必须绑定到该实例。

**绑定方法值。** `make_instance` 中的 `get_value` 函数用 `get` 在类中找到具名属性，然后调用 `bind_method`。绑定方法只对函数值生效，它通过把实例插入为第一个参数，从一个函数值创建一个绑定方法值：

```python
>>> def bind_method(value, instance):
        """Return a bound method if value is callable, or value otherwise."""
        if callable(value):
            def method(*args):
                return value(instance, *args)
            return method
        else:
            return value
```

当方法被调用时，第一个参数 `self` 会被这个定义绑定到 `instance` 的值。

### 2.6.2   类

在 Python 的对象系统和我们这里实现的系统中，类也都是对象。为了简单起见，我们说类本身没有类。（在 Python 中，类确实有类；几乎所有类共享同一个类，名为 `type`。）一个类可以响应 `get` 和 `set` 消息，以及 `new` 消息：

```python
>>> def make_class(attributes, base_class=None):
        """Return a new class, which is a dispatch dictionary."""
        def get_value(name):
            if name in attributes:
                return attributes[name]
            elif base_class is not None:
                return base_class['get'](name)
        def set_value(name, value):
            attributes[name] = value
        def new(*args):
            return init_instance(cls, *args)
        cls = {'get': get_value, 'set': set_value, 'new': new}
        return cls
```

与实例不同，类的 `get` 函数在找不到属性时不会去查询它的类，而是查询它的 `base_class`。类不需要绑定方法。

**初始化。** `make_class` 中的 `new` 函数调用 `init_instance`，后者首先创建一个新实例，然后调用一个名为 `__init__` 的方法。

```python
>>> def init_instance(cls, *args):
        """Return a new object with type cls, initialized with args."""
        instance = make_instance(cls)
        init = cls['get']('__init__')
        if init:
            init(instance, *args)
        return instance
```

这最后一个函数完成了我们的对象系统。我们现在有了实例，它们在 `set` 时局部存储，但在 `get` 时会回退到它们的类。实例在类中查找名称之后，会把自身绑定到函数值上以创建方法。最后，类可以创建 `new` 实例，并在实例创建之后立即应用它们的 `__init__` 构造函数。

在这个对象系统中，唯一应由用户调用的函数是 `make_class`。所有其他功能都通过消息传递来启用。类似地，Python 的对象系统通过 `class` 语句来调用，而它的所有其他功能都通过点表达式和对类的调用启用。

### 2.6.3   使用所实现的对象

现在我们回到上一节中的银行账户例子。使用我们实现的对象系统，我们将创建一个 `Account` 类、一个 `CheckingAccount` 子类，以及它们各自的一个实例。

`Account` 类通过一个 `make_account_class` 函数创建，其结构与 Python 中的 `class` 语句类似，但以对 `make_class` 的一次调用结束。

```python
>>> def make_account_class():
        """Return the Account class, which has deposit and withdraw methods."""
        interest = 0.02
        def __init__(self, account_holder):
            self['set']('holder', account_holder)
            self['set']('balance', 0)
        def deposit(self, amount):
            """Increase the account balance by amount and return the new balance."""
            new_balance = self['get']('balance') + amount
            self['set']('balance', new_balance)
            return self['get']('balance')
        def withdraw(self, amount):
            """Decrease the account balance by amount and return the new balance."""
            balance = self['get']('balance')
            if amount > balance:
                return 'Insufficient funds'
            self['set']('balance', balance - amount)
            return self['get']('balance')
        return make_class(locals())
```

最后对 `locals` 的调用返回一个以字符串为键的字典，其中包含当前局部帧中的名称-值绑定。

`Account` 类最终通过赋值被实例化。

```python
>>> Account = make_account_class()
```

然后，通过 `new` 消息创建一个账户实例，该消息需要一个与新创建的账户相配的名字。

```python
>>> jim_acct = Account['new']('Jim')
```

接着，传给 `jim_acct` 的 `get` 消息会取得属性和方法。可以调用方法来更新账户余额。

```python
>>> jim_acct['get']('holder')
'Jim'
>>> jim_acct['get']('interest')
0.02
>>> jim_acct['get']('deposit')(20)
20
>>> jim_acct['get']('withdraw')(5)
15
```

与 Python 的对象系统一样，设置实例的属性并不会改变它所属类中相应的属性。

```python
>>> jim_acct['set']('interest', 0.04)
>>> Account['get']('interest')
0.02
```

**继承。** 我们可以通过重载类属性的一个子集来创建子类 `CheckingAccount`。在这里，我们修改 `withdraw` 方法以收取手续费，并降低利率。

```python
>>> def make_checking_account_class():
        """Return the CheckingAccount class, which imposes a $1 withdrawal fee."""
        interest = 0.01
        withdraw_fee = 1
        def withdraw(self, amount):
            fee = self['get']('withdraw_fee')
            return Account['get']('withdraw')(self, amount + fee)
        return make_class(locals(), Account)
```

在这个实现中，我们从子类的 `withdraw` 函数调用基类 `Account` 的 `withdraw` 函数，这与我们在 Python 内置对象系统中的做法一致。我们可以像之前一样创建子类本身和它的一个实例。

```python
>>> CheckingAccount = make_checking_account_class()
>>> jack_acct = CheckingAccount['new']('Jack')
```

存款的行为完全相同，构造函数也是如此。取款会通过专门化的 `withdraw` 方法收取 1 美元手续费，而 `interest` 则取 `CheckingAccount` 中更低的新值。

```python
>>> jack_acct['get']('interest')
0.01
>>> jack_acct['get']('deposit')(20)
20
>>> jack_acct['get']('withdraw')(5)
14
```

我们建立在字典之上的对象系统，在实现上与 Python 内置的对象系统相当相似。在 Python 中，任何用户自定义类的实例都有一个特殊属性 `__dict__`，它把该对象的局部实例属性存储在一个字典里，很像我们的 `attributes` 字典。Python 的不同之处在于，它区分出一些与内置函数交互的特殊方法，以确保这些函数对许多不同类型的参数都能正确运作。作用于不同类型的函数是下一节的主题。
